# Security Policy

## Supported Versions

Currently, the `main` branch is the only version receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please send an email to the project maintainer or use GitHub Security Advisories to privately report a vulnerability.

We will try our best to address the issue promptly and will provide an update when the issue has been resolved.
